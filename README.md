# CalcosMath 🧮

**CalcosMath** is a modular, fast, terminal-based math execution tool built in Python. Designed to streamline calculations for high school and university-level algebra, geometry, and computational math.

---

## 🚀 Features

* **Algebra & Geometry Modules:** Solves quadratic equations, distance formulas, pythagorean theorem, and area/volume functions.
* **Command-Line Interface (CLI):** Clean terminal menu system designed for high execution speed without UI bloat.
* **Error Handling & Input Validation:** Built to handle divide-by-zero errors, invalid inputs, and unexpected characters smoothly.
* **Modular Code Architecture:** Functions are separated logically for fast testing and easy expansion.

---

## 🛠️ Tech Stack & Requirements

* Language: Python 3.15.0
* IDE / Environment: VS Code, Terminal / Command Prompt
* Dependencies:** Standard Python Libraries (`math`, `sys`) and Advanced Libraries ('sympy', 'numpy', etc)
