Welcome to Calcos Math, your new future software calculator

We are on the Developer Beta right now. Backend construction is still going on. Soon will add HTML and CSS to it to mimic a real calculator

Run Add, Subtract, Multiply, Divide, Algebra, Geometry and Trigonometry! As well as exponentation


How to RUN!

1. Clone this repository: git clone <your-repo-link>
2. Navigate to the folder: cd calculator
3. Run the script: python calculator.py
